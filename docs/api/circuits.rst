========
Circuits
========

Attribution graphs and interventions, implemented from scratch — no
circuit-tracer ``ReplacementModel``, ``AttributionGraph``, or intervention
machinery. This is the heart of the package; see :doc:`../concepts` for how the
pieces fit and :doc:`../guide/demo` for them in action.

=============
API reference
=============

The public API is organised the way the :doc:`demo <../guide/demo>` uses it:
load a model and its transcoders, build a replacement model, attribute and
prune, then intervene and visualise. Each function's docstring carries the
detail; the :doc:`concepts <../concepts>` page explains how they connect.
